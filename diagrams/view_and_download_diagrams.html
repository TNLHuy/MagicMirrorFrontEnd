🔄 2. Sơ Đồ Luồng Tương Tác Giọng Nói (Voice Interaction Sequence Flow) 
sequenceDiagram
    autonumber
    actor User as 👤 Người dùng
    participant Mic as 🎙️ Micro (RealMicrophone)
    participant STT as 🗣️ Google Speech-to-Text
    participant AI as 🧠 Gemini AI Engine
    participant Srv as 🐍 Python MirrorBackend (:8085)
    participant MM as 🪞 MMM-StateControl (Electron)
    participant Audio as 🔊 Loa ngoài

    User->>Mic: Cất tiếng nói: "Hôm nay thời tiết thế nào?"
    loop Mỗi 50ms (Real-time Audio RMS)
        Mic->>Srv: Gửi biên độ âm lượng MIC_LEVEL (0.0 -> 1.0)
        Srv->>MM: Broadcast MIC_LEVEL
        MM->>MM: Sóng SiriWave tại [BOTTOM_BAR] rung động theo giọng nói
    end
    
    Mic->>STT: Gửi đoạn âm thanh thu được (VAD phát hiện ngắt câu)
    STT-->>Mic: Trả về văn bản tiếng Việt
    Mic->>Srv: Trigger callback text: "Hôm nay thời tiết thế nào?"
    
    Srv->>MM: Cập nhật Bottom Bar: "Đang xử lý..."
    Srv->>AI: analyze_prompt("Hôm nay thời tiết thế nào?")
    AI->>AI: NLU Router phân loại thành SHOW_WEATHER
    AI-->>Srv: Trả về JSON { action: "SHOW_WEATHER", query: "TP. Hồ Chí Minh" }
    
    Srv->>MM: Gửi WebSocket Message { type: "NLU_ACTION", action: "SHOW_WEATHER", ... }
    MM->>MM: Đánh thức [TOP_RIGHT] Widget Thời tiết & Hiển thị thông tin
    MM->>Audio: Phát âm thanh Chime xác nhận
    MM->>MM: Khung Quả cầu tròn [MIDDLE_CENTER] xuất hiện trả lời tóm tắt
